# Локальный бот поиска земельных участков для ИЖС (ГИС «Торги», Хабаровский край)

Автоматизированный Python-скрипт, который получает актуальные сведения о
земельных участках, выставленных на **аренду** через ГИС «Торги»
(torgi.gov.ru) в Хабаровском крае, отбирает лоты под **ИЖС** по заданным
критериям, выявляет риски и ограничения и сохраняет результаты в
Excel-файл с ведением журнала работы.

> **Важно.** Бот является инструментом первичного отбора, а не юридической
> проверкой участка. Итоговое решение об участии в торгах принимается
> пользователем после ручной проверки документов, выписки ЕГРН,
> градостроительной документации и фактического осмотра территории.

---

## 1. Возможности

* Получение списка лотов из **официального JSON API ГИС «Торги»**
  (не эмуляция браузера): аренда земельных участков в Хабаровском крае со
  статусами «Опубликован» / «Приём заявок».
* **Резервный источник** goszemli.ru включается автоматически, если основной
  недоступен (в результатах всегда есть поле «Источник»).
* Фильтрация по региону, типу сделки, статусу, площади, цене аренды, ВРИ и
  местоположению (раздел 6 ТЗ).
* Нормализация данных: площадь (м²/га), цена и период оплаты, срок аренды,
  кадастровый номер, даты.
* Проверка карточки лота и документов на критические ограничения
  (арест, залог, изъятие для государственных/муниципальных нужд, судебный
  спор) и потенциальные ограничения (сервитут, охранные и водоохранная зоны,
  приаэродромная территория, красные линии, зона затопления,
  санитарно-защитная зона и др.).
* Определение расстояния от центра Хабаровска (48.4814° с. ш., 135.0721°
  в. д.) **по формуле гаверсинусов**: координаты из карточки лота → НСПД по
  кадастровому номеру → Nominatim по адресу. Если координаты получить не
  удалось, лот получает статус `distance_unknown` и попадает на лист
  «Требуют проверки» (не удаляется).
* Нормализация цены по правилам: «в год» — как годовая; «в месяц» — ×12;
  «в квартал» — ×4; «начальная цена» без периода, «задаток», «цена лота»
  арендной платой **не считаются**; если период не определён, лот помечается
  `price_period_unknown` и переносится на «Требуют проверки».
* Excel-отчёт с листами «Подходящие», «Требуют проверки», «Отклонённые»,
  «Все лоты», «Сводка»; гиперссылки на карточки и документы; числа —
  числами; кириллица — корректно.
* Журнал работы и ошибок в файле `search.log`.
* Изменение критериев поиска — **без правки кода**, только `config.yaml`.
* Без дубликатов при повторных запусках: записи обновляются по идентификатору
  лота (хранилище `output/state_lots.json`).

Уведомления в Telegram, email или другие мессенджеры не предусмотрены.

## 3. Установка (Windows 11)

1. Установите **Python 3.10 или новее** с python.org (при установке
   отметьте «Add Python to PATH»).
2. Скачайте проект в любую папку, например `C:\torgi-land-bot`.
3. Откройте «Командную строку» в папке проекта и выполните:

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## 4. Запуск

```bat
venv\Scripts\activate
python main.py
```

Пример вывода в консоль:

```
[INFO] Найдено лотов: 128
[INFO] Прошли первичную фильтрацию: 17
[INFO] Проверено карточек: 17
[INFO] Подходящих лотов: 4
[INFO] Требуют ручной проверки: 6
[INFO] Отклонено: 7
[INFO] Отчёт сохранён: output\land_lots_report.xlsx
```

Если консоль отображает «кракозябры», выполните перед запуском
`chcp 65001` или запустите командой `set PYTHONUTF8=1 && python main.py`.

Результаты открываются в Microsoft Excel: `output/land_lots_report.xlsx`.
Параллельно создаётся копия с датой в имени, например
`land_lots_report_2026-11-18.xlsx` (отключается параметром
`output.dated_copy: false`).

## 5. Настройка критериев — config.yaml

Все параметры поиска вынесены в `config.yaml` (правка кода не требуется):

| Параметр | Назначение |
|---|---|
| `region`, `region_code` | Хабаровский край и его код в ГИС «Торги» (`31`) |
| `deal_type`, `type_transaction_code` | аренда (`rent`) |
| `lot_statuses` | статусы «Опубликован» / «Приём заявок» |
| `min_area_m2` | минимальная площадь, м² (600) |
| `max_rent_per_year`, `max_rent_per_month` | порог арендной платы (180 000 руб./год, 15 000 руб./мес.) |
| `max_distance_km` | максимальное расстояние от Хабаровска (50 км) |
| `center` | координаты центра Хабаровска |
| `vri_keywords` | ключевые слова ИЖС |
| `location_keywords` | населённые пункты/районы (пополняется пользователем) |
| `hard_reject_keywords` | критические формулировки → «Отклонённые» |
| `review_keywords` | потенциальные ограничения → «Требуют проверки» |
| `negation_keywords` | отрицания («арест не наложен», «ограничения отсутствуют») — такие находки риском не считаются |
| `access_keywords`, `utilities_keywords` | признаки подъезда и коммуникаций |
| `output` | пути файлов, скачивание документов |
| `request` | паузы 2–5 сек., повторы, размер страницы |
| `geocoding` | НСПД и Nominatim |
| `sources` | основной и резервные источники |

Слово «ограничение» само по себе не является основанием для исключения лота —
оно встречается в стандартных юридических формулировках. Для каждой находки
бот сохраняет найденную фразу, контекст и источник (карточка или документ).

## 6. Листы Excel-отчёта

| Лист | Содержание |
|---|---|
| Подходящие | Лоты, прошедшие все обязательные фильтры |
| Требуют проверки | Лоты с потенциальными ограничениями, неизвестной ценой (`price_period_unknown`), неизвестным расстоянием (`distance_unknown`) или без сведений о подъезде/коммуникациях |
| Отклонённые | Лоты, не прошедшие фильтрацию, с указанием причины |
| Все лоты | Полная выгрузка всех обработанных лотов |
| Сводка | Количество найденных, отфильтрованных, подходящих и отклонённых лотов, дата запуска |

Колонки листа «Подходящие» соответствуют разделу 10.4 ТЗ (ID лота, название,
номер извещения, кадастровый номер, адрес, площадь, цены, ВРИ, категория
земель, форма собственности, срок аренды, дедлайн заявок, расстояние, статус
локации, уровень риска, ограничения, ссылки на лот и документы, источник,
дата проверки). При повторном запуске файл обновляется — дубликаты не
создаются.

## 7. Источники данных

* **Основной** — официальный машиночитаемый API ГИС «Торги»:
  `https://torgi.gov.ru/new/api/public/lotcards/search` (список),
  `https://torgi.gov.ru/new/api/public/lotcards/{id}` (карточка),
  `https://torgi.gov.ru/new/file-store/v1/{fileId}` (документы).
* **Резервный** — `goszemli.ru` (каталог аренды и ИЖС-лотов; используется
  только при недоступности основного, поле «Источник» указывает происхождение
  лота). Каталог резервного источника может быть сохранённым срезом —
  актуальность всегда проверяйте по извещению в ГИС «Торги».

Бот использует корректный User-Agent, делает паузы 2–5 секунды между
запросами, повторяет неудачные запросы до 3 раз, логирует HTTP-статусы.
Учётные данные нигде не хранятся и не требуются. Задача формулируется как
надёжное получение официально опубликованных данных, а не обход защитных
механизмов сайта.

## 8. Обработка ошибок

| Ситуация | Действие бота |
|---|---|
| Сайт недоступен | Повтор запроса до 3 раз, затем переключение на резервный источник и запись в лог |
| Карточка лота не загрузилась | Лот переносится в «Требуют проверки», ошибка в логе, работа продолжается |
| Не удалось определить площадь | Лот не попадает в «Подходящие» (причина в отчёте) |
| Не удалось определить цену | Перенос на «Требуют проверки» (`price_period_unknown`) |
| Не удалось определить координаты | Статус `distance_unknown`, лист «Требуют проверки» |
| Ошибка при сохранении Excel | Запись в лог; если файл открыт в Excel — сообщение «закройте файл» |
| Дубликат лота | Обновление существующей записи, без повторной строки |

## 9. Ежедневный запуск через Планировщик заданий Windows

Встроенный планировщик в коде отсутствует (по ТЗ). Настройка вручную:

1. Win+R → `taskschd.msc` → «Создать задачу…».
2. Триггер: ежедневно, например 09:00.
3. Действие: запуск программы `python.exe`, аргумент `main.py`,
   рабочая папка — каталог проекта.
4. Чтобы использовалось виртуальное окружение, укажите программу
   `C:\torgi-land-bot\venv\Scripts\python.exe` и рабочую папку
   `C:\torgi-land-bot`.

Либо одной командой (от имени администратора):

```bat
schtasks /Create /TN "TorgiLandBot" /SC DAILY /ST 09:00 /TR "C:\torgi-land-bot\venv\Scripts\python.exe C:\torgi-land-bot\main.py"
```

## 10. Ограничения

* Проверка рисков выполняется по тексту карточки, названиям и (при включённой
  опции `output.download_documents: true`) тексту PDF-документов лотов — это
  первичный отбор, а не юридическая экспертиза.
* Геокодирование через Nominatim работает не для всех адресов сельских
  поселений; такие лоты получают статус `distance_unknown` и не удаляются.
* Полная выгрузка ограничена `request.max_pages` страницами выдачи
  (защита от чрезмерной нагрузки на сайт).
